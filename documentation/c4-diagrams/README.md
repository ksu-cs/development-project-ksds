# C4 Diagrams

This folder contains all the C4 diagrams for this project.

## Naming Conventions

Each type of diagram must follow the below naming conventions to be recognized by the wiki:
* System Context Diagram: system-context-diagram.svg
* Container Diagram: container-diagram.svg
* Component Diagram: component-diagram.svg

## Updating Diagrams

To update a diagram, delete the corresponding diagram in this folder and then replace it, ensuring the correct naming conventions are followed. These updates should automatically be reflected in the wiki.
