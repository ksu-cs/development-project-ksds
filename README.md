# Where Did They Go?

development-project-ksds is an interactive web application that aggregates rural migratory data in the State of Kansas. Additional data that might reveal insights into the cause of such migration is displayed alongside an interactive map. This project seeks to identify the cause of documented rural outmigration in Kansas. In the future, we could expand this project to other states in the U.S. or even other countries.

## Licenses

The data aggregated and displayed through this web appliation is typically publicly available. Citation for all data used can be found in the Wiki (Still Working On It).
