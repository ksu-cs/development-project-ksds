# 02 Input Slider

## Move the input slider one step to the right

Expected Changes:
* The year selected below the input slider should go from 1860 -> 1870.
* The borders on the map should change to match the selected year.
* The first section of railroad, on the far right of the map, will be rendered.



## Move the input slider to its max value

Expected Changes:
* The year selected below the input slider should go from 1870 -> 2020.
* The input slider will be unable to manually be moved the last step, which would represent the year 2030.
* All railroads should be rendered to the map as green lines.
* The borders on the map should change to match the selected year.



## Move the input slider to its min value

Expected Changes:
* The year selected below the input slider should go from 2020 -> 1860.
* All railroads should be hidden on the map.
* The borders on the map should change to match the selected year, as seen when the application first launched.
